# Core Workflows

This section covers the day-to-day tasks you will perform in Axiom.

## Available workflow guides

| Workflow | Description |
| --- | --- |
| [LEI Records](./lei-records) | Search and view Legal Entity Identifier data |
| [Settlement Instructions (SSI)](./ssi) | View and manage standard settlement instructions |
| [Countries](./countries) | Browse ISO 3166 country reference data |
| [Currencies](./currencies) | Browse ISO 4217 currency reference data |
| [Languages](./languages) | Browse ISO 639-1 language reference data |
| [Entities](./entities) | View legal entity master data |
| [Instruments](./instruments) | View financial instrument master data |
| [Accounts](./accounts) | View account static data |

## Workflow page structure

Every workflow page follows the same structure:

1. **Goal** — what you will accomplish.
2. **Prerequisites** — what you need before you start.
3. **Steps** — how to complete the task.
4. **Expected result** — what success looks like.
5. **Common issues** — problems you might encounter and how to resolve them.
6. **Related tasks** — where to go next.
