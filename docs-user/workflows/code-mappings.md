# Code Mappings

## Goal

Browse and filter code mappings between source systems in Axiom.

## Prerequisites

- You are signed in to Axiom. See [Sign In & Access](../getting-started/sign-in-and-access).

## Steps

### Search mappings

1. Open **Code Mappings** from the Reference Data section.
2. Use the **Search** field to filter by system, type, code, or description values.
3. Results update as you type.

### Apply column filters

1. Use paired **From** and **To** filter fields.
2. Set values for system, type, code, and status as needed.
3. Filters combine with **AND** behavior.
4. Use **Clear Filters** when active filters or search terms are present.

### Adjust page width

1. Click **Expand / Normal** in the page header.
2. Choose **Save as my default** when prompted to persist your preferred width.

## Fields

| Field | Description |
| --- | --- |
| From System | Source system for the input code |
| From Type | Source code type/category |
| From Code | Source code value |
| To System | Destination system for the mapped code |
| To Type | Destination code type/category |
| To Code | Destination code value |
| Status | Mapping state (`Active` or `Inactive`) |
| Description | Human-readable mapping context |

## Expected result

You can quickly find mappings, narrow results with paired filters, and keep your preferred layout width.
