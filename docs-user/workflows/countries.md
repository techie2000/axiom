# Countries

## Goal

Browse and search ISO 3166 country reference data in Axiom.

## Prerequisites

- You are signed in to Axiom.

## Steps

1. Click **Countries** in the top navigation.
2. Use the **Search** bar to find a country by name or ISO code.
3. Click a row to view the full country record.

## Fields

| Field | Description |
| --- | --- |
| Alpha-2 | Two-letter ISO 3166-1 code (for example, `GB`) |
| Alpha-3 | Three-letter ISO 3166-1 code (for example, `GBR`) |
| Numeric | Three-digit ISO 3166-1 numeric code |
| Name | Official English country name |
| Continent | Continent classification |
