# Countries

## Goal

Browse and search ISO 3166 country reference data in Axiom.

## Prerequisites

- You are signed in to Axiom. See [Sign In & Access](../getting-started/sign-in-and-access).

## Steps

### Search for a country

1. Click **Countries** in the top navigation.
2. Type in the **Search** bar to filter by country name, ISO alpha-2 code, or alpha-3 code.
3. Results update automatically as you type.

### Filter by continent or region

1. On the Countries page, locate the filter bar below the stats cards.
2. Use the **Continent** dropdown to show only countries in a specific continent.
3. Use the **Region** dropdown to narrow results further to a sub-region.
4. Click **Clear Filters** to reset all active filters.

### View country details

1. Click any row in the countries table to open the detail panel.
2. The panel shows all available fields for the selected country.
3. Press **Escape** or click **Close** to dismiss the panel.

### Customise visible columns

1. Click the **Columns** button in the page header.
2. Check or uncheck columns to adjust what is displayed.
3. Click **Save as default** to persist your column selection across sessions.

Available columns include: Flag, Name, Native Name, Alpha-2, Alpha-3, Numeric Code, Capital,
Continent, Region, Languages, Currency Codes, Phone Codes, and Active status.

### Adjust page width

Click the **Expand / Normal** toggle in the page header to switch between a wider table view and
standard width. Your preference is saved automatically.

## Fields

| Field | Description | Example |
| --- | --- | --- |
| Flag | Country flag emoji derived from the alpha-2 code | 🇬🇧 |
| Name | Official English country name | `United Kingdom` |
| Native Name | Country name in the primary local language | `United Kingdom` |
| Alpha-2 | Two-letter ISO 3166-1 code | `GB` |
| Alpha-3 | Three-letter ISO 3166-1 code | `GBR` |
| Numeric | Three-digit ISO 3166-1 numeric code | `826` |
| Capital | Capital city name | `London` |
| Continent | Continent classification | `Europe` |
| Region | Sub-region within the continent | `Northern Europe` |
| Languages | Languages spoken in the country | `en` |
| Currency Codes | ISO 4217 currency codes used in the country | `GBP` |
| Phone Codes | International dialling codes | `+44` |
| Active | Whether the country record is active in Axiom | `Yes` |

## Expected result

You can find any ISO 3166 country by name or code, filter by continent or region, and view all
available country attributes.

## Common issues

| Issue | Possible cause | Resolution |
| --- | --- | --- |
| Country not found | Search term does not match name or code | Try the alpha-2 or alpha-3 code directly |
| Continent filter shows no results | The selected combination has no matching entries | Clear the region filter and try continent only |
| A column is not visible | It may be unchecked in the column selector | Open the Columns panel and enable the column |
| Native name is blank | Not all records include a native name translation | This is expected for some territories |
