# Currencies

## Goal

Browse and search ISO 4217 currency reference data in Axiom.

## Prerequisites

- You are signed in to Axiom.

## Steps

1. Click **Currencies** in the top navigation.
2. Use the **Search** bar to find a currency by name or code.
3. Click a row to view the full currency record.

## Fields

| Field | Description |
| --- | --- |
| Code | Three-letter ISO 4217 currency code (for example, `USD`) |
| Numeric | Three-digit ISO 4217 numeric code |
| Name | Official currency name |
| Minor Unit | Number of decimal places (for example, 2 for USD) |
| Countries | Countries where the currency is used |
