# Instruments

## Goal

View and search financial instrument master data in Axiom.

## Prerequisites

- You are signed in to Axiom.
- Your role includes access to the **Instruments** module.

## Steps

1. Click **Instruments** in the top navigation.
2. Use the **Search** bar to find an instrument by name or identifier.
3. Click a row to view the full instrument record.
