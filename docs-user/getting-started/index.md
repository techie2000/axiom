## Quick overview

Axiom is organised into the following main areas:

- **Master Data** — countries, currencies, entities, instruments, and accounts.
- **LEI Records** — Legal Entity Identifier data sourced from GLEIF.
- **Settlement Instructions (SSI)** — standard settlement instruction management.
- **Admin** — user approvals, translation review, and sync triggers (admin users only).

Your menu will show only the sections you have permission to access.
